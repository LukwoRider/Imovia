# Imovia Project Documentation

## Overview

Imovia is a real estate rental management application designed for property owners, real estate agencies, and tenants. Its goal is to centralize and simplify property management through a single, intuitive platform.

The application allows users to manage properties, track their status, handle rentals, plan maintenance, and manage incidents reported by tenants. A dashboard provides a clear overview of the real estate portfolio.

Imovia aims to improve communication between stakeholders, reduce administrative workload, and provide a secure and modern solution for rental management.


## Features

-   Secure user authentication
-   User profile management
-   Document and resource management
-   Real-time communication features
-   Modular and scalable architecture
-   Cross-platform mobile application


## Technical Stack

### Frontend (Mobile Application)

-   React Native
-   Expo Router
-   TypeScript

### Backend

-   Node.js
-   Express.js

### Database

-   MongoDB / Supabase (depending on environment)

### Authentication

-   JWT / Secure session management

## Installation

### 1. Clone the repository

``` bash
git clone https://github.com/LukwoRider/Imovia.git
```

### 2. Navigate to the mobile application

``` bash
cd frontend/application
```

### 3. Install dependencies

``` bash
npm install
```

### 4. Start the development server

``` bash
npx expo start
```


## Usage

After launching Expo, you can run the application:

-   On an Android emulator
-   On an iOS simulator
-   On a physical device using Expo Go
